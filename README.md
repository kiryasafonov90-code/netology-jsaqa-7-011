# Нетология — 7.1. JavaScript в браузере: отладка

## Задание 1

В `main` находятся `index.html` и `.vscode/launch.json`.

1. Откройте папку репозитория в VS Code.
2. Установите Google Chrome и нажмите **F5** (конфигурация `Launch index.html`).
3. В открывшемся Chrome проверьте текст `hello world`.

## Задание 2

В ветке `breakpoints` добавлен оператор `debugger;`. Pull Request показывает изменения относительно `main`.

Для сдачи требуются **два настоящих скриншота VS Code**: остановка на строке `debugger;` и остановка на точке, выставленной щелчком слева от номера строки `console.log(x);`. Добавьте их в GitHub Issue. Запуск VS Code и создание скриншотов выполняются на локальном компьютере.
